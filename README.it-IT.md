## Cosa Fa optimizerDuck e Perché è Importante

Windows funziona bene appena installato. Tuttavia, un'installazione pulita include anche servizi in background, telemetria, app preinstallate e attività pianificate che continuano a funzionare anche se non le usi mai. Questi consumano risorse di sistema come CPU, RAM, disco e rete in background.

Allo stesso tempo, molte impostazioni che possono migliorare le prestazioni, ridurre la latenza o offrire un'esperienza più fluida non sono abilitate di default.

optimizerDuck riunisce tutto in un unico posto. Ti aiuta a ottimizzare Windows, rimuovere componenti non necessari, personalizzare le impostazioni di sistema e gestire le funzionalità comuni di Windows senza dover frugare nel Registro di sistema, nei Criteri di gruppo o in PowerShell.

Include anche strumenti di gestione integrati, che ti permettono di vedere cosa è in esecuzione, rimuovere ciò di cui non hai bisogno e ripristinare le modifiche ogni volta che è necessario.

**[Perché ottimizzare Windows?](#perché-ottimizzare-windows-invece-di-aggiornare-solo-lhardware)**

### Ottimizzazioni di Sistema

Oltre 30 ottimizzazioni in 6 categorie, ognuna con una descrizione chiara e un livello di rischio, così sai esattamente cosa fa ogni modifica prima di applicarla.

| Categoria | Cosa copre |
| :----------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Prestazioni** | Ottimizzazione dell'host dei servizi in base alla tua RAM, regolazioni delle priorità dei processi, riduzione della latenza della tastiera e modifiche allo scheduler multimediale per un gaming più fluido |
| **Privacy** | Disabilitazione della telemetria di Windows, segnalazione errori, ID pubblicitario, tracciamento posizione, Cortana, Copilot e suggerimenti per la consegna dei contenuti |
| **GPU** | Modifiche al registro specifiche per vendor AMD, NVIDIA e Intel, che coprono stati di alimentazione, clock gating e latenza di visualizzazione |
| **Alimentazione** | Disabilitazione di ibernazione e avvio rapido, disattivazione della sospensione selettiva USB, installazione di un piano di alimentazione personalizzato ad alte prestazioni e disabilitazione del throttling energetico |
| **Bloatware e Servizi** | Blocco del comportamento di reinstallazione delle app OEM e ottimizzazione del tipo di avvio per oltre 200 servizi di Windows |
| **Esperienza Utente** | Rimozione dei ritardi di visualizzazione dei menu, disabilitazione di effetti visivi come animazioni della barra delle applicazioni e trasparenza per una sensazione più reattiva |

> [!NOTE]
> Le ottimizzazioni qui sono state ricercate da strumenti noti con una vasta base di utenti, nulla è generato dall'IA o aggiunto alla cieca. Ogni modifica è scelta per il suo impatto reale.

### Personalizzazione

Non c'è bisogno di frugare nel registro, solo interruttori, menu a tendina e campi numerici presentati in un unico posto. Organizzato in quattro categorie:

- **Desktop**: Mostra o nascondi icone (Questo PC, Cestino, Rete, File utente, Pannello di controllo), rimuovi l'overlay della freccia dei collegamenti
- **Preferenze**: Allineamento della barra delle applicazioni, widget, pulsanti Visualizzazione attività e Termina attività, secondi dell'orologio, modalità scura, estensioni dei file, file nascosti, cronologia appunti, visualizzazione compatta, assistenza allo snap, caselle di controllo elementi, menu contestuale classico e ricerca Bing
- **Gaming**: Modalità Gioco, Barra dei giochi, registrazione in background, accelerazione del mouse, ottimizzazioni schermo intero, pianificazione GPU con accelerazione hardware
- **Sistema**: Abilita Bloc Num all'avvio

### Strumenti Integrati

| Strumento | Cosa fa |
| :-------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Dashboard di Sistema** | Visualizza CPU, RAM, GPU, unità di archiviazione e dettagli del sistema operativo in un unico pannello |
| **Gestore Avvio** | Vedi ogni app e attività che si avvia all'avvio, attivale/disattivale e apri la loro posizione file |
| **Attività Pianificate** | Sfoglia, esegui, arresta, abilita, disabilita o elimina le attività pianificate di Windows |
| **Pulizia Disco** | Scansiona e cancella file temporanei, cache di sistema, residui di Windows Update, prefetch, miniature, cestino, dump di arresto anomalo e vecchie installazioni di Windows |
| **Rimozione Bloatware** | Elenca tutti i pacchetti AppX rimovibili con badge di rischio (Sicuro, Attenzione, Sconosciuto), così puoi scegliere cosa rimuovere |

### Perché ottimizzare Windows invece di aggiornare solo l'hardware?

Il modo più veloce per migliorare le prestazioni è sempre aggiornare l'hardware. Una CPU, una GPU, più RAM o un SSD più veloci di solito portano miglioramenti molto più grandi rispetto alle sole modifiche software.

Ma l'hardware è solo una parte del quadro.

Windows è progettato per centinaia di milioni di PC con hardware, carichi di lavoro e utenti diversi. Per questo, Microsoft distribuisce Windows con impostazioni che privilegiano compatibilità, stabilità, durata della batteria e facilità d'uso invece delle massime prestazioni.

Di conseguenza, un'installazione predefinita di Windows include molti servizi in background, attività pianificate, telemetria, funzionalità di risparmio energetico e app preinstallate che molti utenti potrebbero non aver mai bisogno.

Questo è particolarmente vero dopo aver reinstallato Windows. Anche dopo aver installato tutti i driver e gli aggiornamenti, molte impostazioni utili legate alle prestazioni rimangono intoccate, mentre componenti di background non necessari continuano a funzionare.

Ottimizzare Windows significa semplicemente ridurre l'overhead non necessario in modo che il tuo PC possa dedicare più risorse a ciò che conta davvero, che sia il gaming, la programmazione, la creazione di contenuti o il lavoro quotidiano.

Non raddoppierà magicamente i tuoi FPS, ma può ridurre l'attività in background, abbassare la latenza del sistema, migliorare la reattività e aiutare il tuo hardware a funzionare in modo più coerente.

Questo è anche uno dei motivi per cui molte persone consigliano Linux per migliori prestazioni e un overhead di sistema inferiore. Se preferisci rimanere su Windows per la sua compatibilità software e la sua esperienza familiare, optimizerDuck ti aiuta a ottenere la migliore esperienza possibile senza cambiare sistema operativo.

### Quando dovrei ottimizzare Windows?

Il momento migliore è **dopo aver configurato un'installazione pulita di Windows**.

Consigliamo questo ordine:

1. Installa Windows.
2. Installa tutti i driver hardware (chipset, GPU, rete, audio, ecc.).
3. Esegui **Windows Update** finché non ci sono più aggiornamenti disponibili.
4. Installa tutti gli **Aggiornamenti facoltativi**.
5. Apri il **Microsoft Store** e aggiorna tutte le app integrate.
6. Installa il software e i giochi che usi normalmente.
7. Applica le ottimizzazioni di optimizerDuck che preferisci.
8. Usa gli strumenti integrati di optimizerDuck per rimuovere app non necessarie, pulire Windows e gestire i programmi di avvio.

Seguire questo ordine aiuta a evitare che Windows o gli aggiornamenti dei driver sovrascrivano le tue ottimizzazioni in seguito.

> [!TIP]
> Molti utenti avanzati scelgono di disabilitare temporaneamente gli aggiornamenti automatici di Windows dopo aver terminato la configurazione. I grandi aggiornamenti di Windows possono ripristinare le impostazioni predefinite, reinstallare alcuni componenti o annullare alcune ottimizzazioni. Se lo fai, ricordati di riattivare periodicamente Windows Update per installare importanti aggiornamenti di sicurezza prima di disabilitarlo di nuovo.

> [!NOTE]
> Ogni ottimizzazione fornita da optimizerDuck può essere eseguita anche manualmente. L'obiettivo di optimizerDuck è semplicemente rendere l'ottimizzazione di Windows più facile, sicura e comoda.

## Sicurezza

La modifica delle impostazioni di sistema comporta dei rischi. optimizerDuck è costruito intorno alla reversibilità e al controllo dell'utente.

Vedi la [Privacy Policy](./PRIVACY.md) per i dettagli sulle nostre pratiche relative ai dati.

- **Backup automatici**: Ogni modifica scrive un file di ripristino in una cartella locale. Puoi ripristinare singole modifiche o annullare tutto
- **Ripristino con un clic**: Annulla qualsiasi ottimizzazione applicata dall'interfaccia con un solo clic
- **Classificazione del rischio**: Ogni modifica è etichettata come Sicura, Moderata o Rischiosa in base al suo potenziale impatto
- **Nessuna impostazione predefinita applicata**: Nulla viene eseguito finché non lo selezioni. Lo strumento non abilita nulla da solo
- **Promemoria punto di ripristino**: Prima della tua prima ottimizzazione, l'app suggerisce di creare un punto di ripristino di Windows

## FAQ

> [!TIP]
> Visita la nostra [Pagina FAQ sul sito web](https://optimizerduck.vercel.app/docs/faq/general) per altre domande e risposte.

### optimizerDuck è sicuro da usare?

Sì. optimizerDuck è completamente **open-source** (GPL v3), il che significa che chiunque può ispezionare, verificare o compilare il codice sorgente autonomamente. Ogni release è compilata automaticamente da **GitHub Actions** dal sorgente pubblico; nessuna modifica nascosta, nessun binario non firmato iniettato dopo la compilazione. Se preferisci, puoi clonare la repo e compilare il `.exe` da solo con un singolo `dotnet build`.

L'app **non** raccoglie alcuna telemetria, dati di utilizzo o informazioni personali. Vedi la [Privacy Policy](./PRIVACY.md).

### optimizerDuck migliora davvero le prestazioni, riduce la latenza o velocizza la mia rete?

Può aiutare. Ogni ottimizzazione in optimizerDuck è **ricercata da strumenti noti, guide della community e raccomandazioni dei produttori di hardware**, nulla è generato dall'IA, aggiunto alla cieca o inventato. Ogni modifica riguarda una vera impostazione che Windows configura in modo conservativo di default (es. raggruppamento host dei servizi, stati di alimentazione GPU, throttling di rete, pianificazione dei processi).

Qui non ci sono falsi hack del registro, ogni modifica ha uno scopo documentato e un impatto reale supportato da test della community e documentazione dei vendor.

### Perché Windows SmartScreen / Defender segnala il download?

optimizerDuck non è firmato con un certificato di firma del codice perché i certificati sono costosi per i progetti open-source. Quando Windows incontra un eseguibile non firmato scaricato da Internet, SmartScreen mostra un avviso per impostazione predefinita. Questo è normale e **non** significa che il file non sia sicuro.

Per aggirare l'avviso, clicca su **"Ulteriori informazioni" > "Esegui comunque"**. Se sei ancora preoccupato:

- Compila tu stesso il file `.exe` dal [sorgente](https://github.com/itsfatduck/optimizerDuck)
- Invia il binario a sandbox online come ANY.RUN per una verifica indipendente

### Posso annullare le modifiche se qualcosa va storto?

Sì. Ogni ottimizzazione crea un file di ripristino prima di essere applicata. Puoi annullare singole modifiche o ripristinare tutto dall'interfaccia con un solo clic. L'app suggerisce anche di creare un Punto di Ripristino del Sistema di Windows prima della tua prima ottimizzazione.

### Funziona su Windows 10 e Windows 11?

Sì. optimizerDuck supporta **Windows 10 (x64)** e **Windows 11 (x64)**.

### Ho bisogno dei diritti di amministratore?

Sì. optimizerDuck modifica le impostazioni di sistema e il registro di Windows, quindi richiede privilegi di amministratore per essere eseguito.

### optimizerDuck raccoglie i miei dati?

No. L'app non contiene telemetria, analisi o funzionalità di chiamata a server esterni. Funziona completamente offline e non invia alcun dato da nessuna parte.

### Perché Gestione Attività mostra il 100% di CPU dopo aver applicato il piano di alimentazione? ([#29](https://github.com/itsfatduck/optimizerDuck/issues/29))

Un bug noto di visualizzazione di Gestione Attività attivato da piani di alimentazione non predefiniti, riporta erroneamente il 100% di CPU su alcuni sistemi mentre il carico effettivo è normale. Solo visivo, **non** influisce sulle prestazioni reali né causa surriscaldamento. Se non desiderato, disattiva semplicemente questa ottimizzazione.

## Risoluzione dei Problemi

> [!TIP]
> Visita la nostra [Pagina di Risoluzione dei Problemi](https://optimizerduck.vercel.app/docs/faq/troubleshooting) per una guida più dettagliata e soluzioni alternative ai problemi noti.

### L'app non si avvia o si blocca all'avvio

Assicurati di eseguirla come **Amministratore**. optimizerDuck richiede privilegi elevati. Se continua a bloccarsi, scarica l'ultima versione da [Releases](https://github.com/itsfatduck/optimizerDuck/releases/latest); una build obsoleta potrebbe essere incompatibile con la tua versione di Windows.

### Le modifiche non sembrano avere effetto dopo l'applicazione

Alcune ottimizzazioni richiedono un **riavvio del sistema** per essere applicate completamente. Se una modifica non sembra funzionare dopo il riavvio, prova ad applicarla di nuovo o controlla la sezione di ripristino per verificare che la modifica sia stata salvata.

### File di ripristino mancante o danneggiato

I file di ripristino sono archiviati in `%LocalAppData%\optimizerDuck\Revert\`. Se un file viene accidentalmente eliminato o danneggiato, puoi ripristinarlo da un backup o creare un **Punto di Ripristino del Sistema** in anticipo come fallback.

### Windows Update ripristina le mie impostazioni

Gli aggiornamenti delle funzionalità di Windows occasionalmente reimpostano alcuni valori di registro e configurazioni di servizio ai valori predefiniti. Basta riapplicare le ottimizzazioni precedenti dall'app dopo un aggiornamento importante.

### Ho trovato un bug / voglio richiedere una funzionalità

Apri una [segnalazione](https://github.com/itsfatduck/optimizerDuck/issues) su GitHub con quanti più dettagli possibili: la tua versione di Windows, cosa hai applicato e cosa è andato storto. Anche le richieste di funzionalità sono benvenute.

## Dettagli Tecnici

- **Framework**: WPF su .NET 10, utilizzando la libreria WPF UI per il design Fluent
- **Sistema di ripristino**: Quattro tipi di step di ripristino (Registro, Servizio, Attività Pianificata, Shell) con stato persistito in JSON e I/O su file thread-safe
- **Temi**: Modalità Scura (predefinita), Chiara e ad Alto Contrasto con supporto per sfondo Mica
- **Nessun installer**: Funziona come un singolo .exe, non richiede installazione
- **Sistema di backup**: Backup basato su cartella locale per ogni modifica, con ripristino in un clic
- **Discovery**: Le categorie di Ottimizzazione e Funzionalità vengono scoperte automaticamente tramite reflection + attributi personalizzati, nessuna registrazione manuale necessaria
- **Nessuna telemetria**: L'app non raccoglie alcun dato utente
